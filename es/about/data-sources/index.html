    Fuentes de datos

    Datos meteorológicos

    Le ofrecemos un modelo único, a diferencia de otras aplicaciones que muestran modelos de centros nacionales.

    Obtenga más información en la siguiente página: Modelo Meteo-Parapente

    El modelo Meteo-Parapente utiliza datos de: NOAA, ECMWF, DWD, METEO-FRANCE, METEOSWISS, AEMET, UKMO, EUMETSAT, NASA, JMA, COPERNICUS, y muchos más.

    Geografía

    Los datos geográficos provienen de OpenStreetMap

    Espacio aéreo

    El mapa del espacio aéreo es proporcionado por openAIP - Base de datos mundial de aviación

    Lugares de parapente

    Los lugares de parapente son proporcionados por ParaglidingEarth
